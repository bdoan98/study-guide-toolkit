# Study Guide Toolkit

A centralized library of AI-powered study guide plugins, reusable skills, prompts, templates, and formatting systems for generating structured, exam-focused study materials.

This repository is a modular collection of AI study-guide components designed to transform lecture notes and course materials into clear, high-yield study guides for assessment prep.

## Breakdown

| Component | Purpose | Output Focus |
| --- | --- | --- |
| Plugins | Extend workflows for ingesting notes and source materials | Consistent preprocessing and extraction |
| Reusable Skills | Encapsulate repeatable study-guide generation behaviors | Reliable structure across topics |
| Prompts | Guide AI outputs toward exam-relevant coverage | Concise, high-priority concepts |
| Templates (HTML/PDF) | Standardize final guide presentation | Printable and shareable study artifacts |
| Formatting System | Enforce layout, hierarchy, and emphasis rules | Structured, scannable exam-focused guides |
